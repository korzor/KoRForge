# Titulo: Reversion de versiones de addons y mejoras del sistema

- **Regresar a version anterior**: boton directo en la tarjeta del addon para restaurar su version previa ante fallos.
- **Respaldo automatico pre-actualizacion**: instantanea de seguridad del addon antes de instalar cualquier version nueva.
- **Perfiles rapidos (Presets)**: guarda y alterna facilmente entre configuraciones de addons activos (Raid, JcJ, etc.).
- **Exportar lista de addons**: copia toda tu lista de addons en formato tabla Markdown al portapapeles.
- **Progreso en tiempo real**: visualizacion de megabytes descargados y porcentaje durante la actualizacion.
- **Rendimiento optimizado**: busquedas instantaneas gracias a nueva cache en memoria y escaner acelerado.
