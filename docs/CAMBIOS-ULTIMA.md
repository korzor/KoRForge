# Titulo: Descargas secuenciales 1 por 1 y deteccion robusta de versiones

- **Descargas 1 por 1**: las actualizaciones masivas descargan e instalan los addons de forma estrictamente secuencial.
- **Soporte para addons pesados**: soporte completo para addons de gran tamaño como OpenMap o paquetes de audio.
- **Detección de versiones mejorada**: el actualizador detecta con total fiabilidad las nuevas versiones disponibles.
