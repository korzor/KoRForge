# Titulo: 1.5.1 - Correcciones de UI: botón instalar, favoritos y modal de compartir

- Pestaña Favoritos: eliminada la píldora redundante de versión instalada para mayor limpieza visual.
- Botón de instalación: tamaño unificado con el botón de instalado, acabado naranja translúcido con reborde sólido, tipografía blanca y eliminación del icono de rayo.
- Modal de compartir: nuevo icono vectorial de nodos, diseño reorganizado en tarjetas claras para código de texto (TXT) y paquete completo (.kfg).
